# Corpus de régression — Atelier des Rives

Dix rapports entièrement fictifs et vingt questions préparés pour les essais de la maquette. Ces exemples ont servi à repérer les erreurs du 17 octobre 2026 ; ils sont maintenant des cas de régression connus, pas un jeu de validation indépendant.

Les rapports peuvent être importés dans Mes documents. Le fichier questions.csv contient le corrigé : ne pas l’importer dans le RAG. Aucun de ces fichiers n’est chargé automatiquement dans l’espace personnel.

Exécuter `python -m scripts.evaluate_rives --local` pour essayer le vrai modèle local sur les questions libres ; sans cette option, seuls les faits vérifiés et les extraits sont utilisés.
